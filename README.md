# SteamDeck Agent

An open-source agent for automating common Steam Deck operations.

## Overview

SteamDeck Agent aims to make routine Steam Deck tasks easier by automating them
through a single, simple interface. The project is currently in early
development, so features and usage may change as it evolves.

## Planned Features

> This list is a work in progress and will be updated as the project develops.

- Automate common Steam Deck system operations
- Simple, scriptable command interface
- Safe defaults with clear feedback for each action
- Designed to run directly on SteamOS / Steam Deck

## Requirements

- A Steam Deck (or a Linux system for development)
